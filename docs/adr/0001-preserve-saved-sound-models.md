# Preserve the sound model of saved Pieces

Expressive synthesis and independent room sends change how existing configurations sound. Version-5 projects therefore store explicit Foundation and room modes; versions 1–4 and saved Foundation settings lacking a model version retain classic synthesis and shared room routing, including after re-export. Fresh defaults and complete presets explicitly opt into the new modes, while editing Sound or Depth promotes only that part of the saved sound; this compatibility cost avoids silently replacing a player's existing Piece.
